---
description: Lê uma ou mais páginas pela Bright Data e devolve o conteúdo
argument-hint: <url> [outras urls]
allowed-tools: mcp__brightdata__scrape_as_markdown, mcp__brightdata__scrape_batch
---
Use as ferramentas de scraping do servidor MCP `brightdata` para ler estas páginas: $ARGUMENTS

Para uma URL, use `scrape_as_markdown`. Para várias, use `scrape_batch`. Depois resuma o conteúdo de cada página e destaque os dados mais relevantes. Se o servidor `brightdata` não estiver conectado, diga isso e não tente outro meio.
